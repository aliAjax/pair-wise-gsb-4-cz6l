# License Lens · 发行前依赖门禁台

纯前端的开源依赖许可证发行门禁工具，由原许可证分析原型演进而来。`npm run dev` 启动，数据保存在浏览器 localStorage，刷新后依赖、授权、豁免与批次关系保持一致。

## 门禁裁决

- 每个依赖按 **4 个分发渠道**（内部使用 / SaaS 服务 / 闭源分发 / 开源发布）× **用途**（运行时 / 开发依赖 / 构建工具）分别裁决：放行、待复核、阻断。
- GPL / AGPL 等 Copyleft 组件用于闭源分发（AGPL 含 SaaS）一律阻断，须凭**覆盖该渠道的商业授权**放行；授权过期立即恢复阻断。
- 弱 Copyleft（LGPL/MPL/EPL 等）闭源分发需复核；开发/构建用途不随制品分发，全渠道放行。

## 商业授权与人工豁免

- 商业授权登记供应商、覆盖渠道和有效期，仅对覆盖渠道生效，过期自动恢复原始裁决。
- 人工豁免必须登记适用范围、审批人和失效日，到期自动失效。

## 批次与审核

- 导入新清单（逐行 `名称@版本 许可证 [用途]` 或 package.json）生成**待审核批次**，历史批次保留。
- 批次详情自动比对上一批次，列出**新增、移除和结论变化**。
- 批次审核通过后才成为当前已审核批次；**只有当前已审核批次可导出** Markdown 门禁报告。

## 开发

```bash
npm install
npm run dev    # 本地开发
npm run build  # 类型检查 + 构建
```

核心裁决逻辑在 `src/domain.ts`（纯函数，无 UI 依赖），界面在 `src/App.tsx`。
