# License Gate · 发行前依赖门禁台

由许可证分析原型（License Lens）演进而来的纯前端发行前依赖门禁台。`npm run dev` 启动，数据持久化在浏览器 localStorage，刷新后依赖、授权、豁免与批次关系保持一致。

## 核心能力

- **分渠道 × 分用途裁决**：每个依赖按「内部使用 / SaaS 服务 / 闭源分发 / 开源分发」四个渠道，结合运行时 / 开发用途分别给出结论（通过 / 放行 / 待复核 / 阻断），并展示裁决依据。
- **Copyleft 门禁**：GPL、AGPL 用于闭源分发一律阻断（AGPL 用于 SaaS 同样阻断）；须凭**覆盖该渠道的商业授权**放行；授权到期当日即失效，结论自动恢复阻断。
- **人工豁免**：登记适用范围（渠道）、审批人、失效日与事由；到期自动失效并恢复原结论。
- **批次化导入**：每次导入清单生成一个**待审核批次**，旧批次全部保留，并列出新批次的**新增 / 移除 / 结论变化**；审核通过前报告锁定，**仅当前已审核批次可导出** Markdown 报告。
- **一致性持久化**：批次、授权、豁免统一存储并在加载时校验修复引用关系；裁决结论不落库，始终由规则实时推导。

## 清单格式

- 逐行：`名称@版本 许可证 [runtime|dev]`，如 `sharp@0.34.0 LGPL-2.1`
- 或直接粘贴 `package.json`（自动区分 dependencies / devDependencies，许可证记为 Unknown 待补录）

## 命令

```bash
npm install
npm run dev      # 本地开发
npm run build    # 类型检查 + 构建
```
